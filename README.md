# Meel

Dated facts and shared trips for Indian motorcycle routes. The site lives at **rideplanner.in**.

*Meel* (मील) is Hindi for mile, as in the kilometre stones beside every Indian road.

## How to read this repository

| Folder | What is in it |
|---|---|
| `docs/` | The plan, the research behind it, and the original briefing |
| `design/` | The wireframes: one frame for each situation a rider can be in, with build notes |
| `data/` | Everything the site shows, for fifty routes, with the source of every fact |
| `web/` | The website itself |

Start with `docs/morning-report-2026-09-28.md`, which says what exists and how far to trust it. Then read `docs/plan.md`, and open `design/meel-wireframes.html` in a browser.

## What is true of everything here

- **Hobby first.** One person keeps this, in limited time.
- **Every fact has a source and a date.** Nothing is shown as confirmed until a rider or the editor has confirmed it.
- **Credit is given where data came from.** Map data is from OpenStreetMap contributors. Pictures are from Wikimedia Commons, each with its author and licence. Every fact links to the page it came from. See `data/README.md`.
